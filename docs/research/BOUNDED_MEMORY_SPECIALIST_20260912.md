# Bounded memory specialist: admission before inference

Status: design and source audit; no librarian deployed and no savings/parity claim.
Current Engine evidence: `99fffe28940746998595c64519c8a0103e310e13`.

## Decision

Engine remains the exact archive. A Luna specialist is an optional semantic
retrieval service, not a second archive, permanent conversation, or gatekeeper
between Astra and source evidence. Do not invoke it after ordinary events.

The paid work it must displace is repeated historical investigation by Astra.
The comparator is current Engine-only retrieval, not an artificially forgetful
native agent. A brief added to an unchanged transcript is additional cost.

## Current installed boundary (OBSERVED)

`memory_lifecycle.ReceiptMemory._record` ingests completed execution metadata:
run/receipt references, known producing identities, cwd, bounded command preview,
exit/timing flags, environment identifier, and exact stdout/stderr references.
It invokes no model and does not recapture raw streams. It does **not** currently
capture model-authored research conclusions, supersession, or open semantic
obligations automatically. Thus the example involving the later exclusion of
an 83/60 result cannot be promised from automatic command memory alone.

`core.workflow_memory.Memory` already provides exact record storage, literal
AND search, timeline, bounded retrieval and replay. Search returns references;
it validates the project's existing indexed bodies against raw sources. This
full validation cost remains charged and unchanged. There is no verified
automatic correction graph or complete semantic-history coverage.

`ObserverTree` now imports native child response usage into shared accounting,
separating model/effort, parent windows and child histories. Missing/malformed
source coverage remains visible. This helps audit specialist costs but is not
proof of a complete benchmark denominator or any economic saving.

## Smallest lifecycle candidate (HYPOTHESIS)

1. Caller binds the task question, authorized project/workflow scope, archive
   checkpoint, current constraints and explicit resource limits.
2. Engine performs direct retrieval when references are known; otherwise search
   and neighboring-event retrieval. Do not require a ceremonial three-call path.
3. Return exact evidence immediately when no synthesis is requested. An empty
   search is `NO_MATCH_IN_SEARCHED_SCOPE`, not proof that a fact never existed.
4. Only an explicitly unresolved relation or synthesis question can request
   Luna. Supply bounded candidate sources and known correction links, with
   historical content represented as evidence, never new developer instructions.
5. Luna returns attributed findings, references, conflicts, missing evidence and
   a possible expansion request. Engine validates reference membership/version
   and exact bytes. It cannot certify the truth or completeness of the synthesis.
6. Astra retains direct retrieval, scope expansion and independent interpretation.

Start with at most one specialist inference and no recursive helpers. If the
packet is insufficient, return partial evidence and an unresolved obligation;
do not silently start another agent, fallback model or summary call. Limits
are experimental policy, not permission to truncate a required investigation.
The parent may explicitly continue normally, with all recovery cost counted.

No automatic router should claim that deterministic code knows whether omitted
evidence could matter. Current user constraints remain resident independently
of Luna's ranking. Corrections are append-only source-linked observations;
contradiction does not imply supersession without supporting provenance.

## Persistent state and invalidation

Keep query identity, source checkpoint/root, authorized scope, exact selected
references, completed delivery identity, known correction relationships, query
status and actual cost receipts. Do not persist private chain-of-thought.

A dependency change invalidates applicability of a historical conclusion, not
the historical record. Source mutation/missing identity rejects exact retrieval.
An archive delta after a packet's checkpoint marks coverage as historical until
refreshed. Duplicate delivery is idempotent; conflicting payload under the same
identity fails. A failed memory operation never reruns a completed command.
Optional retrieval failure permits ordinary source investigation; unresolved
semantic authority does not permit deterministic execution.

## Qualification before deployment

First populate identical isolated archives with legitimately available history.
Do not leak evaluator answers, future turns or another arm's conclusions.
Freeze scope and verify exact ingestion before testing relevance selection.

Required cases:

| Case | Necessary behavior |
| --- | --- |
| Superseded result | Recover original claim and supported later correction; retain qualification contract. |
| Changed dependencies | Preserve historical pass but reject current applicability. |
| Latent future relevance | Recover an early exact detail after a later question makes it decisive. |
| Ambiguous contradiction | Return both sources and unresolved relation; do not fabricate consensus. |
| Known reference / simple lookup | Engine answers directly with zero specialist calls. |
| Exhaustion / corruption / hostile archived instructions | Expose limits, preserve exact recovery and instruction authority; no hidden retry. |

Offline gates check record identity, Unicode/exact ranges, scope, replay,
reference validation, budget state transitions, missing coverage, idempotency
and cache-counter arithmetic. They cannot establish semantic parity.

Only after these gates: one preregistered paired continuation comparison,
Engine-only versus Engine+Luna. Same parent model/effort/tools and normal
model-written final answers. Freeze fixtures and prior history; capture all
parent and child responses, including failed attempts and review/recovery.
Separate cached, uncached, cache-write (where applicable), output/reasoning,
latency, Engine reads/index/storage and actually delivered context. Unknown
counters block an economic win claim rather than becoming zeroes.

Net benefit = avoided Astra reconstruction minus specialist inference, Astra
reading/review, coordination, retrieval/recovery and Engine overhead. Report
tokens and priced costs separately using dated tariffs; do not equate them to
included-plan quota. Stop on any missed decisive constraint/correction, reduced
investigation access, unresolved accounting or nonpositive combined benefit.

## Applying improvements to the current agent

Applied now: shared child usage observation in the research server; independent
tool reads batched; exact raw evidence retained; researcher gets a bounded
assignment without a parent-history fork; deterministic CI completion reused.
These are operational changes, not a demonstrated 90% testing-cost reduction.

Not applied: standing Luna summarization, forced terse reasoning, reduced model
effort, suppressed semantic review, output-shape changes, or replacement of
current authority with historical notes. No memory brief is claimed to remove
already supplied desktop history. Promotion requires the paired gate above.

| Mechanism | Source finding | Adjudication |
| --- | --- | --- |
| External-context selective access | RLM lets the model inspect externally held context through a bridge. | TAKE the queryable archive principle; use existing exact retrieval before introducing a general JS runtime. |
| RLM inference cap | `maxLLMCalls` reserves helper calls; action generation and extraction/timeout summaries are separate paths. | REJECT this as a total-call budget. Count every invocation and failure/recovery path. |
| Isolated child context | Child sessions keep intermediate work out of parent reports. | TAKE bounded assignments without full parent-history forks; preserve independent judgment. |
| Deadline/background handoff | Runner can detach parent cancellation and continue background work. | DEFER automatic handoff. Waiting deadline and hard execution budget are different. |
| Child accounting | Private child Session usage exists, but `AgentToolOutput` has no usage field; nested aggregation is not established there. | Keep Helix's separately attributed native response imports; do not infer total cost from parent output. |
| Compaction handoff | Recent-message tail is capped at six; large tool results still clamp to 12,000 head plus 6,000 tail characters. | TAKE separate handoff/state/exact-history roles; reject the claim that the carried tail is fully lossless. |
| Handoff validation | `looksLikeHandoff` accepts any two of eight headings. | REJECT as fidelity or economic qualification; semantic correctness and actual reduction are not tested by headings. |
| Hosted persistent memory | Separate service boundary from the CLI implementation. | DEFER. No private history upload, new archive or service installation for this proposal. |
